# Pranavforge Developer Portfolio

A responsive dark-theme portfolio built with beginner-friendly HTML, CSS and JavaScript.

## How to run
1. Extract the ZIP file.
2. Open the `Pranavforge-Portfolio` folder in VS Code.
3. Double-click `index.html` to open it in your browser (or use VS Code Live Server).
4. Edit `index.html` to customize your introduction, skills, education and contact information.

## Files
- `index.html`: content and sections
- `style.css`: layout, colors and responsive design
- `script.js`: mobile navigation and footer year

## Publish with GitHub Pages
1. Create a public repository named `pranavforge.github.io` in the `pranavforge` GitHub account.
2. Upload the three website files to the repository root (README is optional).
3. Go to Settings > Pages > Build and deployment and choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. Wait for deployment. The site should appear at https://pranavforge.github.io/ (if the username and repository name match).

Note: This site intentionally does not invent a personal email, LinkedIn, or resume link. Add them when ready.
